## 已確認

- 同一 localhost 網站，固定左側六個入口：Dashboard 戰情總覽、Strategy 策略中心、Bots 機器人管理、Risk 風險控管、Logs 系統日誌、Yaozi 市場情報；設定與連線放底部。
- 首次開啟 Dashboard，之後恢復上次頁面、選定項目、子分頁與篩選條件；未儲存表單不得自動套用。
- Strategy 首頁為策略庫；策略詳情使用「策略／回測／參數優化」子分頁，版本紀錄置於「策略」。
- Risk 暫同意監控與設定並存；設定修改與解除鎖存分開。
- 附件僅提供黑灰底、霧金、細框線與終端工具風格，不照抄內容與風控政策。
- 外部 Agent 透過 MCP 操作研究，網頁可手動操作並同步顯示相同任務／結果。Antigravity IDE、Codex、DeepSeek Harness 為候選，相容性尚未驗證。
- MCP 與網頁沿用同一研究服務及既有 Decimal 回測／Optuna；研究任務獨立於客戶端連線；策略草稿不修改運行版本。

## 8088 視覺回饋（2026-09-29）

使用者對六頁整體結構勉強滿意，尚未驗收視覺細節；喜歡參考圖的 alert timeline 與 bot-management。本輪實際以瀏覽器查看 8088 Dashboard／Bots；尚未定位該站來源，不修改其頁面或將 repository 原型當成該站。

- Dashboard 警示改成單一面板的垂直時間軸：細線、嚴重度圓點、等寬時間、小型 severity label、摘要及次要說明；移除每筆事件的獨立框。點擊可進入相關 Bot／事件，不把所有事件變成警報。
- Bots 精簡常駐欄位：狀態、Bot／策略、合約／週期、持倉、今日損益、最後 K 線、操作。環境在頁面層級或必要時顯示小標；版本作次要文字；未實現損益與長異常原因放展開詳情。名稱、合約、狀態不得逐字折行。
- 上方狀態摘要可篩選 Bot；列 hover 顯示輕微底色及明確詳情入口，點擊列展開資訊；告警列以小幅琥珀色標記。加入短時間 hover／展開過渡及 reduced-motion 支援，不用持續閃爍或隨機假即時。
- 收斂全站 badge 數量，金色保留給選取、主操作與關鍵數值；頂部 PID／Worker／連線技術細節收進狀態詳情。
- 8088 現有「INSTITUTIONAL QUANT」、v2.4、假 Supervisor PID／WebSocket 連線、日損 soft 3%、同 BTC 合約雙 Bot 等為原型自行生成內容，不代表已核准需求；接線前須移除或修正為現行 v1 契約。

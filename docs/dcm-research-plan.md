## 指標性質與研究推導

DCM 的主要用途應研究為「前一日價格區間的擴張門檻＋交易環境／成本位置」，不直接把箭頭或總分當完整策略。設 R=H-L>0、x=(C-L)/R，未觸發限幅時：DH-H=(0.8065-19/28+10x/28)R，L-DL=(0.8065-9/28-10x/28)R。因 0<=x<=1，兩個值均介於約 0.12793R 與 0.48507R；所以 DH 位於前日最高價之上、DL 位於前日最低價之下。此為來源公式的數學推導，非市場回測結果；原 ±9.5% 限幅、零振幅或資料異常須另分支處理。

DC 是前日典型價格，不是已證實的均衡價或必然回歸目標。5／20／60 日 VWAP 及日曆週／月／季 VWAP 是不同特徵；原稿混合日 OHLC4 加權歷史與當日圖表 K 線加權量，並非逐筆真實 VWAP。研究版需選擇一致的指定週期近似方法並記錄來源差異。

綜合分數的價格位置、VWAP 與斜率可能重複表達同一趨勢，突破本身也已給 DCM 加分；先保留分項驗證，不把高分解讀成多項獨立確認。原日線 20MA 斜率的 ±1%／±3% 門檻是每日均線變化，不可當成各圖表週期的價格報酬門檻。市場環境應先用決策前已知的日線方向、成本線方向及波動特徵定義；事件研究的環境標籤須在突破前固定，避免事後分類。

## 六組候選及優先順序（建議）

以下多頭與對稱空頭分列往返數，不假設兩側期望值相同。所有觸發在已收盤棒確認，下一根開盤成交；不模擬盤中觸價成交。本輪固定參數見下方實作切片，沒有搜尋最佳值。C 的實作使用 DC／短日均線代理，不宣稱已重現 VWAP 或原稿評分。

| 候選 | 交易假說與規則 | 失效／出場設計 | 優先與代價 |
|---|---|---|---|
| A 順勢突破延續 | 決策前趨勢向上，收盤越過 DH；價格／成本方向及量能先作可比較條件 | 收盤跌回突破位附近失效區；獲利後比較已收盤資料的波動追蹤退出，避免一律等遠端 DC | 保留基準；容易追在擴張末端，盤整反覆假突破 |
| B 順勢突破後回踩 | 先記錄獨立已收盤突破事件；後續棒回到該次凍結 DH 容許區，收盤重新站上，才做多 | 收盤跌破回踩低點減明示波動緩衝；事件逾期取消；獲利比較追蹤退出 | 第一研究主線；有機會縮短失效距離，但可能錯過直接上漲或得到更差成交 |
| C 順勢成本回踩 | 成本線／DCM 方向向上；回落至 DC 或短期一致計算的 VWAP 區，收盤恢復並重新轉強 | 收盤跌破回踩結構；退出比較前方 DH 與趨勢追蹤，逐一研究 | 次優先；價格更便宜不等於有優勢，趨勢轉折時易接刀 |
| D 突破失敗收回 | 非強上升趨勢；先有收盤在 DH 上方的事件，後續棒於有限時間內收回 DH 下方，做空 | 收盤再越過事件高點加緩衝即失效；目標比較進場時凍結 DC／中期成本區及有限等待退出 | 第一研究競爭主線；適合檢查擴張失敗，不稱 OHLC 能證明掃止損；強趨勢再突破會虧損 |
| E 中性區間回歸 | 事前趨勢與成本方向平緩；已收盤棒 low<=DL 且 close>DL，次根開盤做多；反向同理 | 收盤失守事件低點減緩衝；目標採凍結 DC，逾期退出；不攤平 | 次優先；收盤確認後可能已接近目標，成本侵蝕；區間轉趨勢尾端風險高 |
| F 收斂後擴張 | 先前完整日振幅相對更早日的典型振幅偏低，次日突破 DCM 門檻；與 A 無收斂條件對照 | 突破收回或有限時間不延續即退出；成功後比較追蹤退出 | 作突破的環境條件；前日振幅太小會放大訊號與成本，不保證收斂必然突破 |

初步機制推薦為 B 與 D，A 作基準；本輪六組皆實作並比較。此初始推薦不是獲利結論，實測排序與反例見下方結果；不先把不同邏輯合成自動環境切換系統或多 Bot 同合約執行。

## 多交易週期驗證與研究矩陣

本輪將「多交易週期」按 15m／1H／4H 執行矩陣，各策略×週期為獨立回測，沿用單一指定週期、Closed Bar、下一根開盤成交；不取得 1m 細部資料重播。

- 區分初步推薦與實測排序：機制推薦保留為事前假說，開發／驗證段的成本敏感排序另存；最後評估不可回頭改選。
- 各週期比較同一市場、共同正式起訖時間與一致成本來源；預熱根數可不同，但須覆蓋共同指標需要，不讓不同起點製造排名。
- 日 DCM／日數成本特徵及 4／12／24 小時事件窗以實際時間對齊；若 ATR／均線改採固定根數，須揭露它在不同 K 線週期代表不同時間跨度。規則／參數版本及是否重新調參分開保存。
- 每個候選的反例對應可檢查案例，例如突破後立即收回、回踩始終未發生、強趨勢中反向進場、跨日點位漂移、波幅不足以覆蓋成本；同時檢查合成行為反例及真實資料中的不利事件。
- 成果矩陣呈現候選×週期的成本後結果、回撤、交易／事件數、持倉時間、資料品質與不確定性，保留無優勢、低樣本及失敗項目。
- 特定週期不佳可能揭示適用範圍，不要求所有週期都正收益。先在開發／比較資料研究這些差異，不能看過最終評估後再挑最佳週期冒充未使用資料。

## 先取得有區分力的證據，再縮減實作範圍

1. 凍結候選及事前環境定義，先檢查直接突破、回踩成立、突破收回、邊界收回等事件的頻率與條件報酬。可預先指定 4／12／24 小時觀察窗；未取得資料前這些只是觀察計畫。
2. 從假設下一根開盤成交起，分析後續有利／不利移動、收盤路徑、成本後結果，按趨勢／中性、方向、波動及時間分段；OHLC 有利／不利極值只作描述，不據此假設盤中委託撮合順序。
3. 顯示相對於不加該條件的增量效果：回踩比直接突破、量能過濾比不過濾、DCM 比前日高低點突破、VWAP 比簡單均線，避免把市場整體上漲誤認為 DCM 獨有優勢。
4. 檢查退出是否遠於合理目標、下一根開盤後目標空間是否已被吃掉、結果是否集中在少數大單／單一時段；完整往返統計與期末未平部位分開。
5. 先在開發／比較資料內淘汰無證據候選，再對有支持的方向做完整策略與有界參數比較。最終保留資料只作最後評估；所有嘗試包括不佳／放棄變體均留紀錄。
6. 順勢與反轉的事件窗、追蹤退出、波動緩衝及成本敏感度是需要研究的設計，不必先把每個數值交給使用者盲選。只有影響可接受行為與授權的事項才問。

以上是完整研究方向。本輪已交付候選回測、事件理由、已成交往返與不利案例；未完成獨立 4／12／24 小時事件條件報酬、前日高低點消融、VWAP／量能比較或全面參數搜尋，不將這些計畫寫成已驗證。

- 隔夜真實研究需要資金費時間、費率及結算 mark price；空事件 tuple 只能表示零資金費假設。資料不足時明示限制，不能據此宣稱已驗證成本後市場優勢。

## 驗證與成果

1. 合成資料驗證前一日點位、預熱、突破方向、下一根開盤成交、跨日持倉及固定／更新退出差異。
2. 驗證因果性：改動決策時點之後的資料，不能改變該時點以前的點位、訊號與意圖；不能使用歷史最終日收盤／成交量替代當時資訊。
3. 相同輸入、設定與策略版本應可重現結果；留存來源／資料／製品 hash、完整成本假設、命令、訊號理由與結果，包括失敗結果。
4. 合成通過僅證明指定規則與模型行為。真實研究另固定 symbol、週期、日期及成本來源，按時間區分開發／比較／最終評估資料；最終評估資料看過後不得再冒充未使用資料。
5. 真實研究按上述六組假說及事件證據比較成本後結果、收盤權益回撤、持倉時間、方向／時間分段與成本敏感度。具體試驗額度與最終判準尚待設計，不自行執行全市場回測。

交付應包含策略規格、經檢查製品、可重現的隔離驗證證據與研究報告。沒有優勢或證據不足也是有效結論；不以找到正回測結果為無限迭代的停止條件。研究通過不授權自動部署或 Demo／Live。

## 外部研究依據與適用限制

- [Liu／Tsyvinski：Risks and Returns of Cryptocurrency](https://www.nber.org/papers/w24877)：研究歷史樣本的日／週動量；可支持趨勢假說有研究價值，不能證明 DCM 或當前 OKX 小時級策略有效。
- [Wen 等：Intraday return predictability in the cryptocurrency markets](https://www.sciencedirect.com/science/article/pii/S1062940822000833)：2013–2020 樣本指出日內動量與反轉，以及跳躍／流動性等條件差異；本輪取得的是摘要／頁面預覽，未完整審查論文。用於提出分環境假說，非本策略績效證據。
- [TradingView：Repainting](https://www.tradingview.com/pine-script-docs/concepts/repainting/)：歷史與即時計算、未確認資料及回填畫面的差異；研究版須記錄首次可知時間。
- [OKX：Perpetual funding fee mechanism](https://www.okx.com/en-gb/help/perps-funding-fee-mechanism)：持倉成本按實際結算事件處理，間隔可變，不能固定假設所有合約每八小時結算。
- [Bailey 等：The Probability of Backtest Overfitting](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)：候選選擇與重複試驗的過度擬合問題；拓展研究需保留嘗試紀錄及未用來調整策略的最終評估資料。

## 未來每次聊天如何回測：產品方向建議，尚未接入

失敗情境很具體：聊天改一句就重新抓同一行情、反覆跑完全相同的研究，既慢又增加資料版本漂移；把最後評估當作日常調參資料，則會逐步挑出只適合歷史的規則。最小做法是沿用現有本機研究任務，保存資料快照、策略版本、比較設定與研究意圖，不先新增常駐服務或 DB schema。

| 用戶本輪改了什麼 | CatOS 應做什麼 | 代價／限制 |
|---|---|---|
| 只是改寫描述，規則未變 | 回覆現有研究與差異為零，不新增試驗 | 必須把語意收斂成明確規則才能判斷等價 |
| 修改進場／出場／持倉期限 | 同快照重跑受影響候選的開發／驗證段 | 累計試驗數；已看的最後段不能當全新測試 |
| 更換 15m／1H／4H 等週期 | 優先用已確認的該週期資料，缺資料才補 | 共同正式起訖、預熱時間與成本不能漂移 |
| 增加 VWAP／量能條件 | 先核對 volume 單位與可知時間，產生新資料／特徵版本 | 不是只改提示詞；不能把 OHLC 加權近似稱逐筆 VWAP |
| 希望最新行情再評估 | 只補缺少的完整區段，建立新不可變快照 | 舊結果不覆寫；新期間是否已看過需保存 |
| 相同規則、快照、成本再次請求 | 命中結果 cache，回傳同一研究 id | 程式或模型版本改變要重新計算，不只比策略名字 |

資料快照、結果快取與研究會話分工：

1. **資料快照**供同一使用者本機的不同策略共用；內容需含合約、週期、OHLC／所需量能、實際資金費事件、mark 模型、metadata 與缺口。不是社群集中帳戶或多租戶服務。
2. **結果指紋**包含策略製品 hash、正規化參數、快照 hash、時間切分、預熱、成本與撮合／指標版本。精確命中才回用；不同變體仍記為研究嘗試。
3. **研究會話**保存已確認偏好（如允許隔夜、D 雙向）、未決問題、候選推導、被否定的理由、累計試驗與已使用的最後評估範圍。AI 換模型／斷線／換對話仍能接續；不是依賴模型記住聊天全文。

我建議保留「AI 助手 → MCP／其他客戶端適配 → 同一 CatOS 研究 API → 持久任務 → 報告」分層。MCP 負責把能力提供給用戶熟悉的 AI；回測排程、資料品質、版本、成本與結果保存由 CatOS 承擔。未來介面協議改變，只需換適配，不需重做研究核心。這是本專案的設計建議，不能宣稱 MCP 不會被替代。

現有七工具已具 `research_catalog`、submit、get_run／result／report 等基本形狀，但**現在仍只核可固定 SMA／合成資料**；本輪 DCM CLI 不等於已能從 MCP 執行。下一個接入工作應先核對經檢查 DCM 製品與資料快照的精確 id／hash／成本契約，再復用既有任務，不讓 AI 傳任意 URL／程式直接執行。Worker 仍只算訊號，程式故障隔離不宣稱 OS 安全沙箱。

研究互動應按階段使用資料，而不是每一句話都跑完整市場：先做來源理解與因果性反例，再有界比較多機制，只有有證據者進入規則細化；最後評估前凍結名單，評估後再討論能保留什麼。用戶看到「這次改動、回測目的、使用的資料、試驗累計、差異與下一個真正需要回答的問題」。已確認偏好不再重問，模型可自行查明的內容不丟回給用戶。

取得較長資料的選擇：

| 方式 | 優點 | 缺點與目前證據 |
|---|---|---|
| 公開 REST | 精確限定合約／區段、容易補缺口；本輪已實際使用 | 需要分頁、限速與覆蓋檢查，不適合每次聊天重新整批抓 |
| 官方歷史下載＋REST 增量 | 先建立多年行情，再只補缺口，適合長期反覆研究 | 需另驗證下載格式、時間日界、重複／缺口、資金費及 mark 的配對；本輪未實作 |
| 每次由 AI 臨時各找資料 | 開始簡單 | 來源／費用／日期容易變，難重現，不建議作平台主流程 |

[OKX 官方歷史資料頁](https://www.okx.com/historical-data) 列 K 線自 2023-07、資金費率自 2022-03；這是較長歷史建置的可調查起點，不代表已下載或已取得精確結算 mark。本輪限制來自所選 85 日切片及已驗證資料，不宣稱全站歷史只能取得 85 日。單一短樣本沒有優勢時，先補跨環境證據，不無限加參數直到回測轉正。

## 交易者校準：收回反轉與發動後成本回踩（2026-10-11）

第三例使用者判讀是：突破 DH 且收盤站上 DH 為強多發動，通常等待之後幾天拉回 DC、DL、周成本或月成本找機會進場。它同時提供「不當下追價」與「發動事件之後才尋找成本回踩」的框架；AI 不應只將此例描述為不做反轉而略過順勢機會。突破 DH 的價格事件，不等同本輪自訂 strength=0.15 門檻。

## 共振決定入場方式：最新已確認偏好（2026-10-11）

使用者針對成本回踩明確說明：通常搭配其他指標增加勝率；若附近有大量成交區 POC、EMA 均線支撐、SNR，或 SMC 的 OB／FVG 等共振支撐／壓力，觸及就會進場做多或做空。若沒有其他共振支撐／壓力，則等收盤確認守住／站回才做多或做空。這是交易者的入場偏好與改善勝率假說，尚非已驗證勝率／期望值提高；不要求同時具有所有列舉指標，不擅自增加必須兩個或三個共振的門檻。

此回覆先限定成本回踩情境；不自行取消前面假跌破的收盤站回要求，也不把所有支撐／壓力接觸都當交易。研究框架需保留發動事件、交易方向、成本回踩位置與失效條件。附近的同方向有效區域須在觸價前已可知；進場後形成的 POC、EMA 或 OB／FVG 不得補作進場理由。

AI 下一個可交付成果應主動提出可追溯的共振定義與正反例，讓使用者核對畫面，而非要求使用者先列完所有參數：

| 要素 | 待驗定義與最小證據 | 具體失敗情境 |
|---|---|---|
| 附近／重疊 | 記錄成本價或區域、額外支撐／壓力區域、已知時間；以事前指定的距離或波動比例界定附近，保留連續距離數值 | 事後把附近範圍放大到任何進場都有共振；支撐與壓力方向不符仍計分 |
| EMA | 先單獨提出固定週期／長度與斜率、已完成 K 線的支撐／壓力解讀；以圖例校準，與無 EMA 的相同入場模型比較 | 用觸價所在棒最終收盤更新 EMA，再假設此前盤中已知道它；多條相似均線重複計為獨立確認 |
| POC | 固定 profile 的起訖、價格分箱、成交量來源與當時截點；日曆或事件錨定範圍是待選方案，不使用事後完整可視區間 | 最終整段 profile 或未來成交量回填歷史；只有整根成交量卻宣稱已精確重建價格成交量分布 |
| SNR／OB／FVG | 優先採使用者實際指標的明確程式規則；記錄區域形成、確認、有效／失效時間與方向；未收到來源時只能提出明示研究版本 | 後來才確認的轉折點或區域被畫回過去，誤稱當時已能掛單；多個相同來源的結構標籤被重複加分 |

TradingView 官方說明 POC 是指定期間成交量最高的價位，其 Volume Profile 使用較低週期資料估算價格成交量分布；不是單一 OHLC 加整根總量可精確推出。[Volume Profile 方法](https://www.tradingview.com/support/solutions/43000502040-volume-profile-indicators-basic-concepts/)。本地 Candle／研究 CSV 尚無量能欄位；原公開 pages 雖保留量能，也不足以自動等同 TradingView 的 POC。若按既有指定週期做近似 profile，必須明示分配模型、量能單位與範圍敏感性，不擅自下載 1m 或宣稱已重現其輸出。

### 分開驗證共振與成交時機

先比較「沒有共振、收盤確認」與「指定單一共振、收盤確認」，使用相同資料、退出、持倉與成本模型，估計條件篩選的增量效果；再在相同共振事件集比較「觸價」與「收盤確認」。觸價與收盤可能形成不同成交集合，需分列全事件、實際成交、錯過行情與虧損事件，不能只比較兩者剛好都有成交的勝率。逐項加入 EMA、POC 或結構區域，不直接搜尋所有指標組合直到轉正。這是建議研究設計，尚未實作或執行。

報告同時列成本後平均盈虧、勝率、平均獲利／虧損、回撤、交易數、成交率與未成交機會；共振的價值須由結果證實，不能只用勝率變高判定策略改善。

### 觸價執行與現行邊界

現行 `catos/research.py` 為固定市價意圖、收盤決策／下一根開盤成交，沒有限價、盤中觸價偵測或撮合契約。因此本次只記錄需求，不改核心、策略、資料、DB、Worker／Supervisor 或執行政策，新增回測／市場資料下載 0。一般網頁檢索只核對方法與官方說明，不是交易資料採集。

後續最小可討論方案是：已收盤資料先形成共振區並凍結委託價，委託在之後棒才生效，以指定週期 OHLC 建立保守觸價近似，另定跳空、觸價未成交、同棒進場／失效順序、逾期與成本假設；它不重現盤中才形成的動態共振，也不保證觸價全量成交。更細的盤中模型屬另一驗證範圍，不能因使用者描述人工做法便自行解除 Closed Bar／無 1m 重播限制。TradingView 亦使用 broker emulator 的盤中路徑假設；Bar Magnifier 改以較低週期資料提高撮合細節，仍屬模型。[策略撮合說明](https://www.tradingview.com/pine-script-docs/concepts/strategies/)。這些是未定案方案，非新的執行授權。

## 2. G 與真實帳戶之間的具體缺口

| 缺口／失敗情境 | 最小補齊方式 | 驗證成本與界線 |
|---|---|---|
| 合成 `risk_equity`／`margin_ok` 無法說明真實權益或可用保證金 | 定義帳戶欄位、幣別、估值時點與可用額度判斷；不直接把某個名稱相似的欄位代入 | 固定脫敏資料＋手算案例；不新增強平撮合模型 |
| G 的 `Report.revision` 及 `complete=True` 是測試證據，交易所未必提供同等欄位 | 保存來源、時間、exchange IDs、分頁／區間覆蓋；由適配器建立完整性證據 | 亂序、重複、缺頁、WS 重連案例；不能用到達次數代替交易所版本 |
| G 的 fills 保存歸因與部位，未形成完整現金／費用／funding 對帳 | 列明各帳務項目來源，核對總權益及差額；避免同筆費用再次扣入日損 | 小型帳單案例；沿用自身歸因記錄，不預建虛擬分帳 |
| 訂單、成交及帳戶快照可能來自不同時點 | 組合快照附完整性與時間窗口，補查後才開 gate | 成交跨快照邊界、分頁遺漏與回報延遲案例 |
| G 排除受管訂單後由本地計算 remaining，實際快照可能重複包含它們 | 用穩定 ID 做來源歸併；不能只相加 pending 總量 | 同筆委託同時出現在 WS／查單／本地的案例 |
| 假交易所不能驗證端點、帳戶模式、tag、逾時語義及保護單 | I 核對適用官方文件；J 才在明確授權的 Demo 環境演練 | 不宣稱目前 payload 即可直接對接 OKX |

## 3. 資料來源與標準化契約

以下保留 H 的來源類別需求；已查證欄位、適用限制、離線合成樣本與尚未完成的整合見 [I-a 契約](okx-readonly-contract.md)。合成樣本不是帳戶錄製證據。

所有組合快照至少記錄：帳戶／環境、合約、資料來源、來源時間（若提供）、接收時間、覆蓋範圍、完整性、證據 ID。帳戶與 Demo／Live 命名空間不可混用。金融 JSON 數值直接保留為十進位字串，不經 float；缺值不能當作零。

| 資料 | 候選來源類別（待查證） | 標準化與必須交叉核對 | 不足時行為 |
|---|---|---|---|
| 帳戶與模式 | 帳戶設定、持倉模式、權限資訊 | 專用子帳戶、環境、cross／net、受支援產品；不把讀取成功當成交易資格 | 禁止開倉；不自動切模式 |
| 合約規格 | 商品資料 | 合約面值／幣別、張數、tick／lot／min、交易狀態及規格版本 | 禁止用研究合成規格下單 |
| Closed Bar | 公開 K 線資料 | 週期、時間邊界、closed、連續性；缺 K 不由 1m 盤中重播補造 | 暫停策略決策，風險監控獨立持續 |
| Mark／估值 | 公開 mark 與帳戶估值 | 價格幣別、時間、各來源可接受偏差與新鮮度 | 禁止增加曝險；陳舊部位不得假定可減倉 |
| 權益 E、風控權益 E_risk | 帳戶餘額／權益／抵押品資訊 | 總權益包含哪些損益；USDT 換算與非 USDT 資產處理；`E_risk = E_verified`，不扣 equity buffer | 未支援資產不自行估值；關閉增倉 |
| 可用保證金 | 帳戶可用額度、掛單占用及產品限制 | 不把 available 當總權益；與本地 reservation 分清是否已包含，避免重複扣減或漏算 | `margin_ok` 不得預設 True |
| 已成交部位 | 持倉快照＋自身去重成交 | 合約張數、方向、歸因、取樣窗口；與最後已核實部位推進結果核對 | 差異隔離，不能直接覆寫本地部位 |
| 普通／條件委託 | 待成交、歷史、單筆查詢及回報 | client／exchange IDs、剩餘量、狀態、受管／陌生分類；條件單清單不可省略 | UNKNOWN 或未支援委託留在責任清單 |
| 成交／費用／funding | 成交明細與帳單 | 穩定 ID 去重、時間與範圍覆蓋、費用符號／幣別及對應委託 | 缺交易／帳單不能聲稱完整終態或帳務已對帳 |
| 外部流量 C_t | 入出金、劃轉與其他帳單類別 | 每類明確列入／排除，淨流入為正；返佣／分潤等依 P4 定案 | 未分類者留待核對，禁止增加曝險 |
| 日初 E_0 | 台北午夜證據或經核准重建結果 | 固定分母、日識別、來源與覆蓋；不可用啟動權益取代 | 缺基準關門，保留既有鎖存 |

I 還須交付「新鮮度／時間窗口參數表」：mark 年齡、帳戶年齡、來源時間差、查詢逾時、重疊查詢區間及時鐘偏差容許值。數值待資料與 API 行為查證後提出，H 不用任意秒數宣稱可交易。

## 4. 2026-09-12 P2–P6 決策狀態

| 政策 | 已確認內容／未定邊界 |
|---|---|
| P2 | 陌生部位／委託禁止增倉，不自動歸因、接管或處置 |
| P3a | 取消 equity buffer；`E_risk = E_verified`。不把可用保證金當權益，不省略保證金檢查 |
| P3b | 被動超限只禁止增加曝險；合法減倉始終允許；不做自動去槓桿 |

| P5 | Soft／Hard 可配置，v1 預設 10%／20%；觸發鎖存、不自動解除。原原因消失且恢復條件合格後可隨時人工 re-arm，包含同日；修改門檻不直接解除 latch |
| P6 | 每 Bot 獨立比例、預設 0% 停用；整倉保護隨平均成本更新，失敗禁增倉並告警、不自動減持。見 [已確認契約](disaster-stop-policy.md) |
